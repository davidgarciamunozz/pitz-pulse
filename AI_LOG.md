# AI-assistant usage log

These are five concrete engineering interactions, paraphrased rather than presented as transcripts. The human reviewer made the final scope and acceptance decisions; repository evidence and tests were used to verify the outcomes.

1. **Masking refinement.** **AI task:** adversarially review the narrow CNPJ/RFC/email/phone masker. **AI result:** identified a word-boundary false negative around reference context and gaps in common Mexican and Brazilian phone formats. **Human decision:** accepted focused regex/test corrections, including the parenthesized Mexican area code, while declining a broad PII framework or general-purpose detection. **Verification:** regression and Annex A unchanged-content tests in [tests/test_masking.py](tests/test_masking.py); preserved in commit `f71ef85`.

2. **Reference labels before model exposure.** **AI task:** independently challenge the initial human classifications. **AI result:** argued that the month-end financial-report deadline in MSG-02 supported `media`, and recurring duplicate charges in MSG-12 supported `bug`/`backend`. **Human decision:** changed those frozen reference labels before any official model evaluation, while retaining other documented ambiguities. **Verification:** [etiquetas_esperadas.json](etiquetas_esperadas.json) and its history from `c26172f` to `f71ef85`; later V1/V2 runs did not rewrite the labels.

3. **Unicode API-key authentication.** **AI task:** read-only security review of the FastAPI layer. **AI result:** identified that `secrets.compare_digest()` on non-ASCII Python strings could raise `TypeError`, incorrectly turning a bad header into a server error or rejecting a valid Unicode key. **Human decision:** approved a narrow UTF-8 byte comparison, not a broader authentication redesign. **Verification:** ASCII, Unicode, and invalid-byte cases in [tests/test_api.py](tests/test_api.py), committed with the API in `f3fb2b8`.

4. **Evaluation integrity before live execution.** **AI task:** audit the evaluator as experimental infrastructure before the first official V1 run. **AI result:** found four defects: sibling workers could outlive an abort; incomplete retry evidence could appear complete; comparison accepted partial runs; offline scoring/export did not verify the prompt fingerprint. **Human decision:** required localized fixes before allowing live evidence, without changing the classifier or V1. **Verification:** fake-provider, cancellation, accounting, comparison, and fingerprint tests in [tests/test_evaluation_runner.py](tests/test_evaluation_runner.py) and [tests/test_evaluation.py](tests/test_evaluation.py), committed as `93fb59c` before V1 evaluation.

5. **V1-to-V2 prompt experiment.** **AI task:** analyze actual V1 mismatches and propose general, non-benchmark-specific prompt rules. **AI result:** suggested tighter intent, priority, ownership, follow-up, and Spanish-summary guidance. **Human decision:** froze V2 in commit `62ea160` before observing output; retained the failed `v2-01` infrastructure attempt, approved a controlled `v2-02` retry only after connectivity diagnosis, then kept V1 when V2 corrected six fields but regressed six and still missed Spanish-summary compliance. A later V3 added only an output-language rule after the runtime Spanish-summary policy exposed Portuguese-request failures; its V4 follow-up was rejected on evidence (see README). **Verification:** frozen prompts, [V1 run](evaluation/runs/v1-01/), [failed V2 run](evaluation/runs/v2-01/), [valid V2 comparison](evaluation/runs/v2-02/comparison.json), and evidence commit `d659ebb`.
